# psy120L-final-report
Decision Making Study
This repository contains the published HTML version of my PSY 120L final reproducible report.
This project examined whether exposure to peer norms (risk-normalizing vs. risk-avoiding) influences participants' risk-taking likelihood and resistance to peer norms, and whether those effects are moderated by individual differences in conscientiousness.
The report was created using Quarto and R.
The published report file is index.html.
The dataset is not included in this repository.
